# Visual lighting implementation plan

> **For agentic workers:** Use superpowers:executing-plans for inline execution.

**Goal:** Fully usable visual RGB editor and reusable keyboard lighting themes.
**Architecture:** Separate lighting protocol/storage/transaction module; Ratatui
workspace with shared layout for drawing, mouse hit testing and keyboard focus.
**Tech Stack:** Existing Rust, Ratatui, Crossterm, hidapi, serde.
**Spec:** docs/superpowers/specs/2026-10-31-lighting-design.md

## Global constraints
Wired device3013/Gen2 only. No keymap writes during lighting. Exact backups before
mutations. Verify readback; expose failure/recovery honestly. No new dependencies.

## Review focus
Stale active profile, ignored/uncertain write, unknown original effect, long preset
names/overflow, keyboard-only access and small terminal layout.
